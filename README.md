# Media Library

**Media Library** — локальное приложение для управления личной медиатекой. Оно помогает организовывать, искать и просматривать медиафайлы, хранящиеся на компьютере.

Приложение разработано на Python с использованием Tkinter.

## Возможности

* **Сканирование папок** — добавление директорий и поиск медиафайлов.
* **Определение типов файлов** — поддержка изображений, музыки и видео.
* **Управление библиотекой** — просмотр файлов в виде списка или сетки.
* **Поиск и фильтрация** — поиск по названию, папке, типу файла и тегам.
* **Теги и избранное** — организация файлов и быстрый доступ к нужным материалам.
* **Рейтинги** — возможность оценивать файлы.
* **Плейлисты** — создание пользовательских подборок.
* **Поиск дубликатов** — обнаружение одинаковых файлов с помощью SHA-256.
* **Статистика** — просмотр информации о содержимом медиатеки.
* **Экспорт данных** — сохранение информации в форматах CSV и JSON.
* **Открытие файлов** — запуск медиафайлов в приложениях, установленных в операционной системе.
* **Локальное хранение данных** — сохранение информации о библиотеке в JSON-файле.

## Технологии

* Python
* Tkinter
* JSON
* hashlib (SHA-256)
* CSV
* Mutagen — дополнительная библиотека для чтения метаданных аудиофайлов.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/frxzzone/media_library.git
cd media_library
```

### 2. Запуск приложения

Убедитесь, что Python установлен на вашем компьютере. Затем выполните:

```bash
python media_library_app.py
```

В зависимости от операционной системы может потребоваться команда `python3` вместо `python`.

### 3. Дополнительная библиотека

Для расширенного чтения метаданных аудиофайлов можно установить Mutagen:

```bash
pip install mutagen
```

## Хранение данных

Данные библиотеки сохраняются локально в файле `library.json`. Перед переносом приложения на другой компьютер рекомендуется сохранить резервную копию этого файла.

## Платформы

Приложение предназначено для настольных компьютеров с поддержкой Python и Tkinter.
